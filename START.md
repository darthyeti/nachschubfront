# So startest du mit Claude Code

1. Neues GitHub-Repository anlegen (z. B. `nachschubfront`) und lokal klonen.
2. Den Inhalt dieses Pakets in das Repository kopieren und einmal committen.
3. Claude Code im Repository-Ordner öffnen.
4. Erster Auftrag, zum Kopieren:

   > Lies CLAUDE.md, docs/GDD.md, docs/PROGRESS.md und docs/meilensteine/M0-projektgeruest.md. Schau dir reference/stiltest.html an. Lege mir dann einen Plan für M0 vor und warte auf meine Freigabe.

5. Für jeden weiteren Meilenstein:

   > Lies docs/PROGRESS.md und docs/meilensteine/M1-spielkern.md. Lege mir einen Plan vor und warte auf meine Freigabe.

6. Nach jedem Meilenstein selbst testen, am Desktop und auf dem Tablet über die GitHub-Pages-Adresse. Rückmeldungen gib Claude Code direkt oder notiere sie in docs/PROGRESS.md.

Designfragen und Balancing-Diskussionen kannst du jederzeit zurück in den Chat bringen. Änderungen am Design sollten danach in docs/GDD.md landen, damit Claude Code sie kennt.
